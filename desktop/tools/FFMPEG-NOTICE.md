# FFmpeg

This local development build uses the FFmpeg executable already installed on this PC by MessageExplainer. FFmpeg is a separate third-party program; its license depends on the bundled build configuration. Run `ffmpeg.exe -version` to inspect that configuration.

FFmpeg project and source: https://ffmpeg.org/
Licensing details: https://ffmpeg.org/legal.html

This build is for local evaluation. Before distributing the installer to others, replace the development binary with a documented redistributable build and include its complete license notices and corresponding source offer as required by that build.
